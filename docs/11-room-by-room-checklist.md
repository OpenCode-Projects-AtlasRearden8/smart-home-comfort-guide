# Room-by-Room Checklist

Work through each room once. Tick the boxes as you go — this page is meant
to be used, bent, coffee-stained, and re-run whenever you add a device. If
something isn't in your house, skip it without guilt; the checklist adapts
to the house you actually have.

## Whole house, done once (start here)

- [ ] Family Wi-Fi renamed from the factory default; password changed once.
- [ ] Guest network turned on, with **"guests can't see the local network"**
      enabled (see [Guest Networks](08-guest-networks.md)).
- [ ] Router admin password not default; router firmware updated once.
- [ ] Speaker tone decided per room (see [What Devices Hear](02-what-devices-hear-and-send.md)) —
      speakers in shared spaces, and a muting habit in bedrooms.
- [ ] One date on the calendar each quarter: "device check-up" (20 minutes,
      the [Privacy Settings Table](12-privacy-settings-table.md) in hand).

## Kitchen

- [ ] Speaker placed away from the TV corner; test muting.
- [ ] Speaker's voice history review done (or saving turned off).
- [ ] Microwave/lamp/kettle plug installed, **named something you'll say**,
      one schedule set.
- [ ] Guest Wi-Fi card taped inside a cabinet door for easy handout.
- [ ] Shared shopping list tested once ("add eggs to the list").

## Living room

- [ ] TV and speaker are not best friends (space apart, or mute during
      movie nights to stop accidental wake words from the soundtrack).
- [ ] Indoor camera: placement passes the "would I be comfortable?" test;
      private-mode or physical shutter known to everyone.
- [ ] Camera's **audio recording** off if two-way talk is unused.
- [ ] Lamps on plugs with a named "Goodnight" rule.
- [ ] Household members know the mute (light goes red = ears off).

## Bedrooms

- [ ] Decide your own line: many households prefer **no cameras in
      bedrooms** and speakers muted there. Whatever you pick, make it the
      house rule, on a card.
- [ ] Bedroom speaker: Do Not Disturb hours set; alarm tested once.
- [ ] The router is *not* kept in a bedroom if it can be moved.

## Entry / porch

- [ ] Doorbell or porch camera pointed **inside your property line** (no
      neighbor windows, no sidewalk long-shot).
- [ ] Motion zones drawn: porch and steps, not the street.
- [ ] Person/vehicle/pet detection on if offered; street-noise alerts off.
- [ ] Package-delivery habit: alerts for "porch during 9am-6pm" not
      "porch always."
- [ ] If the doorbell is cloud-heavy and you're fine with that: fine. If
      you want it local: check [Local Control First](07-local-control-first.md)
      before the next replacement.

## Office / study

- [ ] Any camera here is unplugged during calls you'd rather not store.
- [ ] Wi-Fi printer isn't reachable from the guest network (test it).
- [ ] Smart plug for the desk lamp has a work-schedule (9-ish on,
      whenever off).

## Nursery

- [ ] Camera placement: wide enough to be useful, not aimed into the
      en-suite bathroom; audio listening feature reviewed.
- [ ] Notification preferences: nudging the right person at 3am.
- [ ] Screen off by default (motion alerts instead of always-on feeds).

## Basement / garage / utility

- [ ] Sump pump, freezer, and CO/smoke alarms: **not smart devices** — they
      stay plain, dumb, and reliable.
- [ ] Any dehumidifier plug: socket-load rating checked; schedule simple.
- [ ] If the router lives here: guest network confirmed on; a sticky note
      of the two Wi-Fi names and passwords taped inside the door (helps
      household members and future-you).

## Whole house, done once at the end (close-out)

- [ ] Every device is on the **family network**; guest devices get the
      guest network by default.
- [ ] [Family Presets](10-family-presets.md) cards printed and posted in
      the right rooms.
- [ ] [Privacy Settings Table](12-privacy-settings-table.md) review done
      once, per device that exists in your house.
- [ ] A quarterly check-up exists on the calendar — same day as filter
      changes or smoke-alarm batteries, so the habit group together.
- [ ] Every family member knows the house's two universal moves:
      **mute button** and **"unplug, count ten, plug back in."**
