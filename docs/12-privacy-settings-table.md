# Privacy Settings Table

One table, meant to be checked against your actual devices. Open each
companion app, visit each named page once, and make your choices
deliberately — then stop worrying about it. Most settings here are
set-once-and-forget.

Names differ slightly by brand ("Data & Privacy," "Voice History,"
"Account settings"); the *kind* of setting is the same everywhere, which is
what the table tracks.

## Speakers

| Setting to find | Where (usually) | Calm default for this guide | What it changes |
| --- | --- | --- | --- |
| Voice / recordings saving | App → Settings → Voice history (or Data & Privacy) | Off, or auto-delete after a short window | Stops saving your spoken requests |
| Wait for wake sound | Settings → Voice | Off if TV triggers wake-ups | Fewer accidental activations |
| Remove linked extras | App → Skills/Actions | Keep only ones you use | Fewer data paths per app |
| Do Not Disturb | App → Device settings | Silence unwanted hours | No evening announcements |
| Explicit filter | App → Voice settings | As suits your household | Content filtering |

## Plugs

| Setting to find | Where (usually) | Calm default | What it changes |
| --- | --- | --- | --- |
| Schedule stored on-device | Check product spec / app | Prefer "local schedule" | Survives internet outages |
| Away mode / randomize | App → Device settings | On before trips | Occupancy illusion |
| Energy data retention | App → Account/Data (if offered) | Off or short | Whether usage stats are kept |
| Third-party sharing | Account → Linked services | Off | Fewer doors for your data |

## Thermostats

| Setting to find | Where (usually) | Calm default | What it changes |
| --- | --- | --- | --- |
| Occupancy sensing | App → Settings | On if your house varies, off if boring | Whether "smart away" acts |
| Learning / auto-schedule | App → Settings | On if you want it to learn; off for strict schedule | Pattern discovery from your habits |
| Geofencing | App → Location | Skip (a schedule gets you 80%) | Uses your phone's location |
| Runtime sharing / analytics | App → Account/Data | Off unless you want community stats | Optional energy-compare programs |
| Partner/utility programs | App → Rewards page | Read before joining | Trade-offs are stated plainly; usually fair deals — decide with eyes open |

## Cameras

| Setting to find | Where (usually) | Calm default | What it changes |
| --- | --- | --- | --- |
| Storage location | App → Device → Storage | Local SD/hub if offered; cloud if you prefer the trade | Whether clips leave the house |
| Audio recording | App → Device → Audio | Off if two-way talk unused | Whether sound is saved with video |
| Detection zones | App → Device → Motion | Draw porch/steps, exclude street | Fewer false alerts, less recorded noise |
| Person/pet/vehicle detection | App → Device → Motion | On if offered | Alert quality |
| Quiet hours | App → Notifications | Overnight silence indoors | Sleep preservation |
| Two-factor login | App or web Account → Security | On | Strongest single security win |
| Motion only | App → Clips / Events | Only motion (never 24/7 recording) | Video volume kept small |

## Accounts (all devices, one visit)

| Setting to find | Where | Calm default | What it changes |
| --- | --- | --- | --- |
| Two-factor authentication | Account → Security | On for whoever manages devices | Locks the account door |
| Third-party data sharing | Account → Privacy | Read once, set your line | Whether analytics go beyond the maker |
| Household members | Account → Family/Members | Only people who need access | Fewer guests in your account |
| Old/unused devices | Account → Device list | Removed when retired | Closes silent doorways |
| Data download/delete tools | Account → Privacy | Know where they are before you need them | The "deletion" escape hatch |

## Print-friendly summary card

> **The 6-minute privacy pass (new device in the house):**
>
> 1. Name it something you'd say aloud.
> 2. Voice history / recordings: off or short auto-delete.
> 3. Audio recording off on cameras (if unused).
> 4. Local storage if offered; cloud only by conscious choice.
> 5. Two-factor authentication on the account.
> 6. Guest network for anything belonging to visitors.
>
> Do this once per device, then go back to drinking tea.
